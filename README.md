# אוטומציית תחזית מזג אוויר שבועית - "תחזית בקליק" 🌤️

אפליקציה אינטראקטיבית, מהירה ומעוצבת המציגה תחזית מזג אוויר שבועית מפורטת לכל יישוב בארץ ובעולם בלחיצת כפתור אחת.

האפליקציה נבנתה במיוחד בהתאם לבקשתך ומציגה ממשק מעוצב ואיכותי (בשיטת Glassmorphism) עם תמיכה מלאה בעברית ובמצב כהה/בהיר.

---

## 📋 מה התוכנית כוללת?

האפליקציה מציגה עבור כל יום ב-7 הימים הקרובים את הנתונים הבאים:
1. **טמפרטורה בצלזיוס (°C)**:
   - מציגה את טמפרטורת המינימום והמקסימום היומית.
   - כוללת **סרגל טמפרטורה צבעוני וויזואלי** שמציג את טווח הטמפרטורה ביחס למזג האוויר בארץ.
2. **מצב השמיים**:
   - תיאור מילולי מדויק בעברית (למשל: "בהיר לרוב", "מעונן חלקית", "גשם בינוני", "סופת רעמים").
   - אייקונים וקטוריים מונפשים ודינמיים (SVG) המשתנים לפי סוג מזג האוויר.
3. **אפשרות לגשם (%)**:
   - מציג את ההסתברות המרבית למשקעים באחוזים באותו היום, מלווה באייקון טיפת מים.
4. **מהירות ממוצעת של הרוח בקמ"ש (km/h)**:
   - מהירות הרוח הממוצעת הצפויה באותו יום בגובה 10 מטרים.

---

## ✨ תכונות מיוחדות וממשק פרימיום

* **זיהוי מיקום אוטומטי (Geolocation)**: בלחיצה על הכפתור "זהה מיקום נוכחי", האפליקציה תשתמש ברכיב ה-GPS של המכשיר שלך כדי לטעון מיידית את התחזית למקום שבו אתה נמצא.
* **תיבת חיפוש חכמה בעברית**: מאפשרת להקליד כל יישוב בישראל או בעולם (למשל: "בת חפר", "ירושלים", "תל אביב", "אילת"). התיבה מציגה השלמה אוטומטית (Autocomplete) של תוצאות בעברית עם שם המחוז והמדינה.
* **עיצוב דינמי המשתנה לפי מזג האוויר**: הרקע של האפליקציה וערכת הצבעים משתנים באופן אוטומטי בהתאם למזג האוויר ביום שנבחר (למשל, זהוב חמים בימים בהירים, כחול-אפרפר רך בימי גשם, וגוונים כהים וסוערים בסופות רעמים).
* **מעבר בין מצב כהה (Dark Mode) למצב בהיר (Light Mode)**: כפתור ייעודי בפינה הימנית העליונה מאפשר לעבור בין המצבים עם אנימציית מעבר חלקה. האפליקציה שומרת את הבחירה שלך לפעמים הבאות.
* **אינטראקטיביות מלאה**: לחיצה על כל אחד מכרטיסי הימים בתחתית תעדכן את הפאנל המרכזי עם פירוט נרחב, כולל תיאור שמיים מורחב ורמת דיוק גבוהה.
* **שמירת מיקום אחרון**: האפליקציה תזכור את היישוב האחרון שחיפשת ותציג אותו באופן אוטומטי בפעם הבאה שתפתח אותה.

## 🚀 איך מפעילים את האוטומציה?

כדי להפעיל את האפליקציה בלחיצה אחת:
1. היכנס לתיקייה `אוטומציית מזג אוויר` בתוך Google Drive שלך.
2. לחץ לחיצה כפולה על הקובץ **`הפעלת התוכנית.bat`**.
3. התוכנית תפתח באופן מיידי דפדפן אינטרנט עם ממשק התחזית העדכני.
   * *לחלופין, תוכל פשוט ללחוץ לחיצה כפולה ישירות על הקובץ `index.html`.*

## 🛠️ פרטים טכניים ומקורות מידע

* **מקור נתוני מזג האוויר**: הנתונים נשאבים בזמן אמת משרתי **Open-Meteo API** (שירות תחזית גלובלי מהמתקדמים והמדויקים בעולם, שאינו דורש תשלום או מפתחות גישה).
* **מקור מנוע החיפוש**: Geocoding API של Open-Meteo המתרגם שמות יישובים בעברית לקואורדינטות גיאוגרפיות.
* **זיהוי מיקום הפוך (Reverse Geocoding)**: שימוש ב-OpenStreetMap Nominatim כדי לתרגם את קואורדינטות ה-GPS של המכשיר שלך לשם היישוב המדויק שלך בעברית!
* **טכנולוגיות**: HTML5, Vanilla CSS3 (משתני עיצוב מותאמים, Glassmorphism, CSS Animation) ו-Pure Vanilla Javascript.
